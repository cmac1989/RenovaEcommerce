# Web Communications Project

### Set up
- clone repo
- install front end packages
    - navigate to client folder
-     run npm install react-router-dom bootstrap react-redux react-bootstrap react-icons @reduxjs/toolkit
- install back end packages
    - navigate to server folder
-     run npm install express mysql2 cors dotenv jsonwebtoken bcryptjs
